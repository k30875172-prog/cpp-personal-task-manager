# Personal Task Manager (C++)

## About the Project
Personal Task Manager is a console-based application developed using C++.

It helps users organize and manage their daily tasks efficiently.

## Features
- Add new tasks
- View all tasks
- Update existing tasks
- Mark tasks as completed
- Delete tasks
- Track pending and completed tasks

## Technologies Used
- C++
- Structures
- Vectors
- Functions
- Loops
- Switch Statements

## Purpose
This project demonstrates the practical implementation of C++ programming concepts.
